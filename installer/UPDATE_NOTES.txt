       RIFTCORE COMPANION - UPDATE v2.0.0

Welcome to RiftCore 2.0! The Next-Generation Hybrid LoL Companion.

* Major 2.0 Feature: Hybrid Architecture
  - Ultra-Lightweight Rust Companion (~40 MB RAM):
    Handles Auto-Accept, 1-Click Meta Runes, AI Draft Coach,
    Tier Lists, and Match History at blistering 0.1s startup speeds.
  - Dedicated Zero-Whitebox Overlay Subsystem:
    In-game HUD now runs in a dedicated DirectComposition overlay engine
    that guarantees 100% true per-pixel transparency, zero white-box frame
    artifacts, and seamless hardware click-through.
  - Automatic In-Match Memory Reclaiming:
    The overlay engine launches dynamically when you enter a match and
    terminates completely when the game ends, releasing ~300 MB of RAM
    instantly back down to ~40 MB.

* Minimap & Live Game Alignment:
  - Pixel-perfect docking above the League minimap for Dragon, Baron,
    Voidgrubs, Red Buff, and Blue Buff timers.
  - Live Scoreboard gold diff banner at top center.
  - Real-time matchup CS/min comparison pill beside game clock.
  - Skill level-up indicator showing optimal ability upgrade path.

* Vanguard Safe & Zero Delay:
  - 100% compliant with Riot Games third-party application policies.
  - Communicates solely through official local LCU REST and Live Client Port 2999.
  - Zero memory tampering, zero game DLL hooks.

* Quality-of-Life & Hotkey Controls:
  - Press Alt + ~ or Ctrl + Space in-game to toggle overlay visibility.
  - Interactive & Preview Mode support in Settings to preview positioning.

Enjoy the climb! Unmatched performance, zero ads, zero compromise.
