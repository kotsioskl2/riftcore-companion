--------------------------------------------------
       RIFTCORE COMPANION - UPDATE v2.0.5
--------------------------------------------------

* Native desktop interface:
  - Rebuilt the application shell in Rust with a native egui renderer.
  - Removed Electron and the embedded WebView from the application build.
  - Recreated the obsidian, cyan and crimson RiftCore visual system.

* Native in-game HUD:
  - The HUD is drawn directly by the Rust application in a transparent window.
  - Added League game-window alignment, always-on-top behavior and click-through mode.
  - Added global hotkeys: Alt + ~, Ctrl + Space and Alt + Shift + ~.
  - Added integrated, top bar, tactical card and minimap pill layouts with draggable modules.
  - Restored minimap objective countdown pins, a numbered own-side jungle route, and optional static ward suggestions.
  - Added minimap scale, flip and offset controls for pin alignment.
  - Restored manual allied ultimate timers and objective phase countdowns for Grubs, Herald and Baron.
  - Added a live champion build drawer with item-set sync to the League shop.

* League Client integration:
  - Added native client status, champ-select roster, profile and ranked summary.
  - Added rune-page and summoner-spell import controls.
  - Kept optional queue auto-accept and user-configurable HUD modules.

* Companion tools:
  - Added a local 5v5 draft simulator with live champion-select sync.
  - Added champion name and role filters.
  - Added a locally saved manual TFT positioning board.
  - Wired HUD CS pace, current gold, ability ranks, inventory, trinket status and objective timers to live data.
  - Restored the Mayhem and Arena card catalog, appearance choices, first-run tour, update notes and tray close flow.

* App updates:
  - Added in-app update download, safe executable replacement and automatic restart.
  - Added the standalone RiftCore.exe update asset to future GitHub releases.
